# Central de Chamados de TI da Colina no GitHub Pages

1. Extraia o ZIP e envie index.html, colina.png e .nojekyll para a raiz de um novo repositório em joaoelcio. Você pode usar o nome chamados-colina.
2. No repositório, abra Settings → Pages. Em Source, escolha Deploy from a branch. Selecione main e /(root), depois clique em Save.
3. Use o endereço que o GitHub exibir em Settings → Pages. Abra em janela anônima e confirme que um chamado fictício chega à planilha.

O formulário envia os dados para o servidor já publicado da Central e usa a mesma planilha. Somente a página e a logo são hospedadas pelo GitHub. Não coloque chaves, arquivos .env ou dados da planilha no repositório. O servidor aceita envios da origem https://joaoelcio.github.io. Se configurar um domínio próprio no GitHub Pages, será preciso autorizar essa nova origem no servidor antes de trocar o endereço.
